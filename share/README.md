# Tabby Remote

A [Tabby](https://tabby.sh) plugin: use your Tabby terminals from your phone or tablet on the same Wi-Fi, paired by scanning a QR code. To install it, ask your agent: "install the Tabby plugin from this zip, follow the INSTALL.md inside".

Security: it opens a port (7681) on your local network, and only paired devices can use it, but a paired device can type into your terminals. Pair only devices you own; turn it off any time in Tabby Settings > Phone access.

Uninstall: quit Tabby, delete the `tabby-remote` folder from Tabby's plugin folder (see INSTALL.md), start Tabby.
